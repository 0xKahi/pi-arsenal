multiverse: replace the `/multiverse` Child Sessions placeholder with a read-only view of the child sessions reachable on the active parent branch, newest first. Each row shows last use, agent, session id, provider/model, thinking level and a spend line (tokens, cache, cost, context usage). Enter opens the child's chronological transcript up to its resumable checkpoint; truncated items open a searchable full preview with copy. Adds shared modal components (block list layer, block navigation, searchable preview, token formatting) ported from pi-qol.
